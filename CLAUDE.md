# tiktok-factory

Usine à vidéos TikTok anime/manga pour @the.asura8, exécutée par des tâches planifiées Claude.

- Pour produire une vidéo @the.asura8 : suivre **AGENT_RUN.md** à la lettre ; pour @iafortous (IA + SEO Radius) : **AGENT_RUN_IA.md** (ne pas explorer le reste du code).
- Charte éditoriale : EDITORIAL.md (résumé) / Notion (version complète).
- Code : factory/ (assets = visuels Kitsu/Jikan, voice = clone Chatterbox ou Piper, render = montage FFmpeg, make_video = point d'entrée).
- Musique : music/ (Pixabay, récupérée avec l'outil pixabay_music d'OpenMontage). Police : fonts/Anton (OFL).
- Règle de style : jamais de tiret cadratin dans les textes produits.
